# MantaCil Panel

MantaCil adalah modifikasi eksklusif dari Pterodactyl Panel dengan antarmuka 3D Glassmorphism, terjemahan Bahasa Indonesia penuh, dan sistem yang dioptimalkan untuk performa tinggi.

## Fitur Utama:
- **3D Glassmorphism UI**: Desain antarmuka yang sangat modern dan interaktif.
- **Bahasa Indonesia**: Diterjemahkan penuh untuk memudahkan pengguna lokal.
- **Auto-Installer Terintegrasi**: Mengimpor Egg khusus (seperti Bot WhatsApp) secara otomatis tanpa intervensi manual.

## Instalasi
Untuk menginstal MantaCil Panel di server Anda (Ubuntu 22.04 / 24.04), gunakan script MantaCil Installer:
```bash
bash <(curl -s https://raw.githubusercontent.com/aisantri17/mantacil-installer/main/install.sh)
```
