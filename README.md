# MantaCil Panel

Panel server canggih racikan MantaCil Team. Ini adalah Pterodactyl Panel yang udah kita modif total biar tampilannya lebih kekinian, enak dipandang (pakai gaya 3D Glassmorphism), dan yang paling penting: **Full Bahasa Indonesia**.

## Fitur Unggulan
- **Tampilan 3D Glassmorphism**: Desainnya transparan, modern, dan nggak ngebosenin.
- **Bahasa Indonesia Asli**: Semua menu dan tombol udah diterjemahin ke bahasa kita, jadi gampang banget dipahamin sama klien.
- **Fitur Privasi (Anti-Intip)**: Kalo lu nambahin orang jadi Admin, mereka cuma bisa ngurusin server mereka sendiri. Cuma lu doang (User ID 1) yang punya akses dewa buat ngeliat seluruh server di panel.
- **Security Toolkit Terintegrasi**: Punya pelanggan bandel yang suka pasang script DDoS atau bikin CPU VPS ngos-ngosan? Tenang, MantaCil bakal otomatis nge-suspend server mereka tanpa ampun.
- **Siap Pakai buat Bot WA**: Udah kita siapin sistem buat langsung narik egg Bot WhatsApp tanpa perlu repot import manual.

## Cara Install
Gak usah pusing baca dokumentasi panjang. Langsung aja sikat pakai script auto-installer kita (pastiin VPS lu pakai Ubuntu 22.04 atau 24.04):

```bash
bash <(curl -s https://raw.githubusercontent.com/aisantri17/mantacil-installer/main/install.sh)
```
